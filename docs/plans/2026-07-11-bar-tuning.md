## Current bar architecture

`home/quickshell/` (assembled + Stylix-themed by `home/hyprland.nix`):

- **`shell.qml`** — root: one `Bar` per monitor, `Toasts`, `CheatSheet`.
- **`Bar.qml`** — layout: left = workspaces + active-window title; center = the
  island; right = volume · network · battery · tray.
- **`Island.qml`** — the signature element. A center pill that morphs by state:
  `clock` ⇄ `media` (now-playing + spectrum) ⇄ `notif` (peek). Border **breathes
  terracotta** while `Agent.active` (a rebuild is running).
- **`Spectrum.qml`** — live audio equalizer, fed by **cava** on the default sink
  (reacts to any source incl. Chrome/YouTube); runs only while shown.
- **`Agent.qml`** — polls "is ClaudeOS working" (nh/nixos-rebuild, or the marker
  `$XDG_RUNTIME_DIR/claudeos-agent`) → drives the pulse.
- **`Notifications.qml`** — the notification server (Singleton). Island peeks
  every notification; the corner **`Toasts.qml`** fires only for actionable
  (has actions) / Critical ones.
- **`CalendarPopup` / `MediaPopup`** — the island's click-through popups.
- **`CheatSheet.qml`** — SUPER+H overlay, task-grouped keybinds, base16 accents.
- **`Theme.qml` / `cava.conf`** — GENERATED by `home/hyprland.nix` (not in source).

## Tuning backlog (unordered — pick what calls to you)

**Spectrum**
- Bar count / thickness (currently 14 thin); try chunkier-and-fewer.
- Colour: flat terracotta → a subtle vertical gradient, or intensity-by-height.
- Smoothing / decay feel; a nicer idle resting line when audio is near-silent.

**Island motion**
- Spring overshoot on the width morph (currently `OutBack`, 0.85) — bouncier vs
  calmer.
- Peek duration (currently 5s) and the clock⇄media cross-fade timing (150ms).

**Media state**
- Album-art thumbnail *inline* in the island (not just the popup).
- Scroll long titles instead of eliding.

**Notification peek**
- Show the app icon / name; colour the dot by urgency.

**Agent pulse**
- Breathing speed (currently 1.1s each way); maybe an outer glow, not just border.
- Broaden the signal: also pulse for heal / morning-desk / auto-update units.

**Bigger swings** (the "what else can we do since it's ours" direction)
- A floating / detached bar (margins, not full-width) — reads even less GNOME.
- Animated workspace pills (spring on switch, occupied-glow).
- Auto-hide-and-peek bar; or corner segments instead of one strip.

## Ground rules (see the rule file)
- Stylix base16 only — never hardcode hex.
- Validate every change with `qml-preview` before rebuild (one bad file blanks
  the whole bar).
- Deploy = `rebuild` → **reboot into the `(hyprland)` entry** (a `switch` strips
  the running Hyprland config — it's a specialisation).
